> 状态：历史快照｜最后实测：2026-08-20｜旧仓库成功 Run：`8b63c9f7-2bc9-4476-9441-8b862666fa19`

## 目标

本手册定义从研究、写作、配音、素材选择到渲染的可复用门禁。原则是：宁可停在可解释的审核状态，也不以错误事实、不相干素材、无权利证据或错误赛事画面凑成视频。

## 标准流程

1. 将任务拆成“事实边界”和“视觉边界”。事实边界列出允许出现的日期、数字、结论和来源；视觉边界进一步拆成不可合并的原子 Beat，每个 Beat 只描述一个主体、地点、动作或状态。
2. 研究产物必须满足最低来源数；来源 URL 必须来自不可变 Run 输入。精确日期和数字只能来自输入、已抓取证据或可重复计算。
3. 写作产物逐句受研究产物约束。网页、无数据页面、数据表、标题卡和时间轴属于覆盖层，不是远程素材查询。
4. 搜索查询固定为“人物/主体 + 年份 + 地点 + 赛事/场景 + 动作”。字幕、镜头语言、时长和完整分镜句不得进入查询；知识类内容使用可独立检索的视觉概念及其同义词。
5. 候选先经过人物、赛事、年份、地点、训练/比赛类型硬锚点，再参与相似度排序。硬锚点不满足时，相似度再高也不得覆盖场景。
6. 自动分析检查版权状态、水印、嵌字、安全、人物和语义标签。不合格的自动候选软删除，保留审计记录后换下一个候选。
7. 只有所有必需 Beat 均有可用片段时才生成 manifest。缺素材时按 Beat 自动补采，整组分析完成后幂等恢复 `media.select`；恢复预算耗尽或仍不匹配才进入 `awaiting_review`。
8. 时间线根据旁白语义、原子 Beat 和素材证据执行单调全局规划。切点不得越过入库片段的 `start_ms/end_ms`，不得为了凑时长读取未选择的后续场景。
9. 成片必须经过解码级音视频 QC；黑帧、静音、流缺失和时长异常为机器门禁。画面含义和创作判断仍使用联系表或抽样播放复核。

## 查询规范

正确示例：

- `张继科 2011年 鹿特丹 世乒赛 比赛 击球`
- `张继科 2011年 巴黎 世界杯 比赛 接发球`
- `张继科 2012年 伦敦 奥运会 比赛 对拉`
- `张继科 训练 发球`

禁止示例：

- `张继科最快大满贯相关画面`
- `张继科在训练中发球，字幕显示445天，镜头慢放`
- `官网页面显示无数据`

## 卡点分类与处置

| 卡点 | 可观察症状 | 根因 | 自动处置 | 需要人工的条件 |
| --- | --- | --- | --- | --- |
| 零来源研究 | `sources < minimum_sources` | 研究适配器没有可靠证据 | 停在研究审核 | 补来源或驳回 |
| 来源错配 | URL 年份/赛事与 claim 冲突 | 模型根据 URL 猜内容 | 标记 validation issue，禁止写作 | 核对证据快照 |
| 数字幻觉 | 输入无该日期/数字，研究擅自新增 | URL 未抓正文却被当成证据 | 自动重写；仍不满足则审核 | 确认新增证据 |
| 不可视觉化分镜 | 网页、表格、黑底文字被当成素材 | 写作层混淆覆盖层和 footage | 改为字幕/图形覆盖在 B-roll 上 | 需要独立信息图时 |
| 宽泛搜索 | 搜到球板评测、混剪或同名内容 | 查询包含主题口号和整句分镜 | 规范化查询并重新搜索 | 无 |
| 赛事冒用 | 鹿特丹素材覆盖巴黎/伦敦场景 | 只有相似度，没有事件硬锚点 | 人物、年份、地点、赛事逐项过滤 | 缺少合法赛事素材时 |
| 下载端失败 | `REMOTE_DOWNLOAD_FAILED` | 平台限流、签名或下载器失效 | 换平台、指数退避，不占覆盖率 | 所有来源耗尽时 |
| 平台要求登录 | `REMOTE_AUTH_REQUIRED` | 公开出口触发机器人校验或内容要求账号 | 视为不可自动重试，跳过该来源 | 显式配置合规认证/商业供应商后 |
| 搜索端失败 | `REMOTE_SEARCH_FAILED` | 平台搜索不可用 | 继续其他来源并记录 provider error | 单一来源不可替代时 |
| 水印/嵌字 | 分析完成但 `awaiting_review` | 候选不满足发布质量 | 自动候选软删除并换候选 | 用户明确接受且权利允许时 |
| 素材分析等待 | Run 停在 media.select | 新素材尚未完成 ASR/视觉分析 | 按 acquisition group 完成后恢复一次 | 分析失败或恢复预算耗尽 |
| 复合剧情节点 | 一个分镜包含多个视觉事件 | 模型分镜粒度不稳定 | 恢复旁白中明确但遗漏的原子 Beat | 无法确定事件先后时 |
| 剧情切换过晚 | 旁白进入下一事件但画面仍停留在上一素材 | 按句数均分覆盖了语义证据 | 具体视觉概念加权的单调全局对齐 | 多个候选同分且涉及人物身份时 |
| 原片片段越界 | 选中片段播完后进入下一段对白 | 片段边界被当作软提示 | start/end 作为硬边界；不足显式记录 padding | padding 超过门禁时 |
| 语速一次调整仍不达标 | 写稿正确但配音无法满足目标时长 | TTS 实际语速不是线性响应 | 测量实际音频并进行受限多轮反馈调速 | 达到轮次仍超差时 |

## 太阳耀斑语义剪辑案例

### 问题与修复

- 初始分镜把耀斑、日冕物质抛射、磁层扰动和极光揉在长句中，导致选片和切点依赖位置均分，画面切换僵硬。
- 写作现在必须输出结构化原子 Beat，包含对应旁白、视觉描述、`must_match` 和 `must_not_match`。这些字段来自本次内容并固化在 Run 中，素材层不再内置太阳、体育或电影题材词典。
- 时间线使用单调 Viterbi 对齐整条故事，而不是逐句贪心选择；`selected_for_scene` 和 `selected_for_narration` 形成候选及旁白边界，明确 Beat 映射优先于模糊位置猜测。
- 片段起止时间成为硬边界。本次成片没有越界和定格补时。
- 研究与写作共享精确数量校验。供应商重试后仍加入无来源数字时，系统确定性改为定性描述，不允许带入成片。

## 发布前验收

- 研究、脚本、素材 manifest 中的日期和数字一致。
- 每个赛事场景都能追溯到同人物、同赛事/地点/年份的素材证据。
- 搜索日志不包含字幕、镜头、时长和整句分镜。
- 被拒绝候选不会在重试时反复占用下载预算。
- 所有使用片段拥有权利状态、来源 URL、内容哈希和使用记录。
- 解码级 QC 必须读取真实音视频，检查流、时长、黑帧和静音；metadata-only 报告不得冒充播放验收。
- 自动生成联系表，按剧情节点抽样检查画面语义和字幕安全区。当前不把抽样检查冒充逐帧多模态语义 QC。
- 语义时间线基准和事件知识清单必须通过，新增故障必须同时提供 `issue_code`、根因、修复方法和回归测试引用。
