# 新增页面下拉框与对标提示验收

结论：本轮界面改动通过本机构建、Web 回归与受控浏览器验收，可交付界面改进；不能据此认定真实小红书采集或生产部署已经通过。

## 改动

- 历史报告使用独立的响应式筛选布局，搜索框、类型和操作按钮对齐；手机按字段换行。读取时禁用搜索/刷新，保留原查询和分页行为。
- 历史报告、对标笔记、频道、文档视频、网页视频及试点反馈的原生下拉框改用现有 UiSelect，保留选项值、禁用条件和提交方式，没有新增依赖。补齐下拉菜单的卡片溢出显示和笔记长标题换行。
- 对标页将身份核验状态分为数量摘要、恢复操作及折叠诊断；不把未登录直接描述成登录失效。新增「连接并补全」复用现有连接状态机，验证后恢复当前笔记身份补采；原始错误码仍可展开查看。

## 收尾审计

- **可见功能与恢复**：审阅 history 查询/分页取消、空状态、失败重试，identity 待续请求及序号校验、取消和人工验证。浏览器实测按钮恢复；诊断折叠不改变失败事实。
- **架构与数据合同**：仅修改 Web 组件和相关 CSS；审阅 HTTP adapter 的规范字段、笔记身份计数校验和原有任务提交调用。没有改动 API、Worker、队列、数据库、对象存储、种子及公共 schema。
- **权限、隐私与来源**：复用原本机连接入口，不新增 URL 输入、外链、凭据存储或 HTML 注入；笔记仍需核验后才获取媒体。登录不表示获得内容再利用授权。未进行完整安全或依赖漏洞审计。
- **完整性与并发**：历史读取继续使用 AbortController 和旧响应校验；补全连接保存当前 profile/selection 序号，后续回调继续检查序号。未修改持久化、事务、幂等、迁移或备份，生产恢复未实测。
- **性能、成本与资源**：沿用已有短期连接、限时轮询和付费任务边界；下拉框复用已有组件，不增加服务端请求。受控检查没有产生付费任务；不等同于容量验收。
- **构建与运维**：Web lint、类型、测试及构建通过，核对现有 release-gates 工作流及先前连接审计的未验证条件。本轮未改变依赖清单、发布配置或告警。用文件 SHA-256 比较测试前后的实际工作树；并发构建产物不能替代源码稳定性校验。
